# Квест: 31 августа

Статичный сайт-квест на чистом HTML/CSS/JS, без сборки и зависимостей.

## Файлы

- `index.html` — разметка всех экранов
- `style.css` — стили (mobile-first, тёплая/пиксельная палитра)
- `script.js` — логика переходов и мини-игр
- `worker/worker.js` — код прокси для Telegram-уведомлений (деплоится отдельно на Cloudflare, не на GitHub Pages)

## Локальный запуск

Просто открой `index.html` в браузере, либо подними локальный сервер (нужен из-за относительных путей при открытии через `file://` в некоторых браузерах):

```bash
python -m http.server 8000
```

и зайди на `http://localhost:8000`.

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub и запушь туда `index.html`, `style.css`, `script.js` в корень (папку `worker/` тоже можно закинуть — GitHub Pages её просто проигнорирует, она не для сайта).
2. В настройках репозитория: **Settings → Pages → Source** выбери ветку (`main`) и папку `/root`.
3. Через минуту сайт будет доступен по адресу вида `https://<username>.github.io/<repo>/`.

## Telegram-уведомления (когда квест пройден до конца)

Сайт статичный и лежит в открытом репозитории — токен бота **нельзя** класть прямо в `script.js`, иначе его сможет забрать кто угодно, кто откроет исходный код страницы. Поэтому токен живёт только на Cloudflare Worker — маленьком бесплатном прокси, который сайт дёргает вместо прямого похода в Telegram API.

### 1. Узнай свой chat_id

Открой Telegram, найди своего бота (по имени, которое ты дал ему в BotFather) и отправь ему любое сообщение (например «привет»). После этого попроси меня (Claude) снова проверить `getUpdates` — я вытащу твой `chat_id` автоматически. Либо сделай это сам: открой в браузере

```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
```

и найди `"chat":{"id": ЧИСЛО, ...}` в ответе — это и есть `chat_id`.

### 2. Задеплой Worker на Cloudflare

1. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com) → зарегистрируйся бесплатно (карта не нужна).
2. В меню слева: **Workers & Pages → Create → Create Worker**. Дай любое имя (например `loveway-notify`) → **Deploy**.
3. Открой созданный Worker → **Edit code**. Сотри содержимое и вставь код из `worker/worker.js` этого проекта → **Deploy**.
4. Вернись на страницу Worker'а → **Settings → Variables and Secrets** → добавь три секрета (тип **Secret**, не Text):
   - `BOT_TOKEN` — токен твоего бота от BotFather
   - `CHAT_ID` — число, которое узнал на шаге 1
   - `QUEST_SECRET` — строка `b46b539e7d1cd5aab84ee03f78d0cb4a` (уже прописана в `script.js`; если хочешь свою — поменяй в обоих местах)
5. Сохрани — Cloudflare сам передеплоит Worker с новыми секретами.
6. Скопируй адрес Worker'а сверху страницы (вида `https://loveway-notify.ТВОЙ-ЮЗЕРНЕЙМ.workers.dev`).

### 3. Пропиши адрес в сайте

В `script.js` найди строку:

```js
const NOTIFY_URL = 'https://YOUR-WORKER-NAME.YOUR-SUBDOMAIN.workers.dev';
```

и замени на адрес из шага 2.6. Запушь изменение — готово.

Когда она дойдёт до финального экрана, тебе в Telegram придёт сообщение: что выбрала на приветствии, какие темы свайпнула вправо («интересно») и куда захотела пойти на уровне 3.

## Что нужно поправить перед отправкой

- В `index.html` в заставке — `[ГОРОД ДЕВУШКИ]`, если хочешь заменить плейсхолдер на название города.
- `NOTIFY_URL` в `script.js` (см. раздел про уведомления выше) — без этого уведомления просто не отправляются, сайт при этом работает как обычно.
